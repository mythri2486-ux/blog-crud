\# 📝 Blog CRUD Application



A full-stack Blog CRUD Application built using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB Atlas.



\## 🚀 Features



\- Create new blogs

\- View all blogs

\- View individual blogs

\- Update existing blogs

\- Delete blogs

\- Search blogs

\- Filter blogs by category

\- MongoDB Atlas database integration

\- RESTful API



\## 🛠️ Technologies Used



\### Frontend

\- HTML

\- CSS

\- JavaScript



\### Backend

\- Node.js

\- Express.js

\- Mongoose

\- CORS

\- dotenv



\### Database

\- MongoDB Atlas
